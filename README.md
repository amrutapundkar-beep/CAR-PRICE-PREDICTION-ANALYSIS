# CAR-PRICE-PREDICTION-ANALYSIS
Car Price Prediction using Machine Learning regression models (Linear Regression &amp; Random Forest) built with Python and Scikit-learn

# 🚗 Car Price Prediction Using Machine Learning

## 🌟 Introduction
In today’s automobile market, determining the fair selling price of a used car can be challenging. Factors such as vehicle age, fuel type, transmission, ownership history, and kilometers driven significantly impact the price.

This project builds a **Machine Learning regression model** to predict the selling price of a car based on historical data and vehicle features.

---

## 🎯 Problem Statement
To develop a regression model that accurately predicts the selling price of a car using relevant vehicle attributes.

---

## 📖 Project Description
The Car Price Prediction system analyzes structured vehicle data and identifies patterns that influence car pricing.

Using data preprocessing, feature engineering, and regression algorithms, the model learns relationships between input features and the target variable (Selling Price).

Multiple regression models are trained and evaluated to determine the most accurate prediction model.

This project demonstrates practical implementation of:
- Data Cleaning  
- Exploratory Data Analysis (EDA)  
- Feature Encoding  
- Regression Modeling  
- Model Evaluation  

---

## 📂 Dataset Information
The dataset contains historical car sales data with the following attributes:

### 🔹 Features:
- Year  
- Present Price  
- Kms Driven  
- Fuel Type  
- Seller Type  
- Transmission  
- Owner  

### 🎯 Target Variable:
- Selling Price  

The dataset enables supervised learning for regression-based price prediction.

## ⚙️ Project Workflow
1. Load and explore dataset  
2. Perform data cleaning  
3. Conduct Exploratory Data Analysis (EDA)  
4. Encode categorical variables  
5. Split dataset into training and testing sets  
6. Train regression models  
7. Evaluate model performance  
8. Predict car prices  

---

## 🤖 Machine Learning Models Used
- Linear Regression  
- Random Forest Regressor  

Random Forest provided better prediction accuracy compared to Linear Regression.

---

## 📊 Model Performance
The model achieved strong prediction performance using evaluation metrics such as:
- R² Score  
- Mean Absolute Error (MAE)  
- Mean Squared Error (MSE)  

Random Forest model showed superior results.
